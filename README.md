# 대구가톨릭대학교 RCY 규정·정책

Next.js App Router + Markdown 정적 문서 사이트. 웹사이트 릴리스 **4.2.0**.

공개 사이트: https://bylaws.dcu.rcy.kr/

## 문서 원본과 자동 배포

웹페이지 본문은 `content/`의 Markdown이 유일한 원본입니다. `main`에 커밋하거나 Pull Request를 병합하면 기존 `Next.js Markdown Pages` 워크플로가 문서 검사 → Next.js 빌드 → 결과 검증 → GitHub Pages 배포 → 공개 버전 검증을 실행합니다. 로컬 저장만으로 공개 페이지가 바뀌지는 않습니다.

| 문서 | 원본 |
| --- | --- |
| 회칙 | `content/bylaws.md` |
| 재무 규정 | `content/finance.md` |
| 동아리방 이용 규정 | `content/clubroom.md` |
| 개인정보 처리방침 | `content/privacy.md` |
| 이용약관 | `content/terms.md` |
| 개인정보 동의서 | `content/consent.md` |
| 촬영·초상 이용 동의 | `content/media.md` |
| CCTV 운영·관리 방침 | `content/cctv.md` |

YAML의 `title`, `description`, `status`, `version`은 필수입니다. `effective_date`는 기본 시행일 `2026-09-01`, `updated_date`는 개정 작성일입니다. 기술적 배포가 의결·공고·개인정보 동의를 대신하지 않습니다.

## 4.2.0 변경

- 문서 간 이동은 **상단 메뉴**, 현재 문서의 조문 이동은 **왼쪽 차례**로 분리했습니다. 작은 화면에서는 차례를 접을 수 있습니다.
- 인쇄 버튼을 **우측 하단**에 고정했습니다. 넓은 화면에서는 최대 1,900px 컨테이너 안에서 본문 폭이 확장됩니다.
- 원본 규정집의 조문 카드·번호·강조·표를 유지하면서 **A4 인쇄용 여백, 글자 크기, 조문 구분선, 반복 표 머리글, 긴 조문의 페이지 분할**을 따로 설정했습니다. 인쇄에는 메뉴·버튼·푸터가 나오지 않습니다.
- 재무 제21조: 홈페이지 회계 페이지로 지출 내역 공유, 종강 2주 이내 학기 결산 작성, 재무부장·부회장·회장 확인. 회칙의 감사·총회 절차를 폐지한 것은 아닙니다. 별도 회계 서비스 구현은 이번 범위가 아닙니다.
- 공용 계정 비밀번호 **1달에 한 번 변경**을 개인정보·CCTV 방침에 명시했습니다. 실제 비밀번호 변경 자동화나 계정 조작은 하지 않았습니다.
- 일반 내부 기록 **최대 5년**, 외부 처리 **해당 서비스·사업 운영기간** 기준을 반영했습니다. 이 작성본의 5년 기산점은 기록 수집·생성일이며, 목적 종료 시 먼저 파기합니다. 건강정보·인증정보·계좌정보·CCTV·얼굴인식 데이터의 별도 기준을 무조건 5년으로 늘리지 않습니다.
- 문의 응대 업무를 개인정보 처리 표에서 제거했습니다. 개인정보 권리 행사·고충 처리 창구는 유지합니다.
- 개인정보 보호책임자·일반 개인정보 담당자: **윤민기 / rcyindcu@gmail.com**. 동의서와 촬영 안내에도 연락처와 보관 기준을 연결했습니다.
- 운영자가 제공한 **Xiaomi Home 클라우드 전송·저장 가능, Xiaomi AI 자동 영상분석, 얼굴인식 데이터 수집·저장** 내용을 반영했습니다. 특정 제품·계약·서버 국가·생체정보 동의·기기 설정을 실제 검증한 것과는 구분합니다.

## 코드와 서식

- 공통 셸: `app/layout.jsx`
- 상단 문서 메뉴: `components/navigation.jsx`
- 왼쪽 차례: `components/table-of-contents.jsx`
- 테마·복사·인쇄: `components/controls.jsx`
- 문서 페이지: `app/[...slug]/page.jsx`
- 규정집 기본 디자인: `app/globals.css`
- 확장 폭·상단 메뉴·차례·인쇄: `app/reading-layout.css`

Markdown의 조문 제목은 `lib/regulation-format.mjs`에서 정화 후 카드로 표시됩니다. 카드용 HTML을 본문에 중복 작성하지 않습니다. 원문·문서별 해시·정적 HTML·다운로드 일치 검사는 계속 유지됩니다.

감사·임원 선발·관리 문서 등 공개 제외 목록은 `retiredSlugs`를 유지합니다. 제외된 원본과 과거 Jekyll 소스는 저장소와 Git 이력에 남지만 새 페이지·검색·다운로드는 생성하지 않습니다. 이전 `_includes/`, `_layouts/`, 루트 문서 폴더를 편집해도 Next.js 본문은 바뀌지 않습니다.

## 실행·배포 확인

Node.js 22 이상과 잠금 파일을 사용합니다.

```sh
npm ci
npm test
npm run build
npm run verify:export
npm run dev
```

GitHub Pages의 Source는 GitHub Actions를 유지합니다. 정적 결과물은 `out/`, 배포 커밋·문서 해시·빌드 시각은 `/version.json`에서 확인합니다. `/downloads/`에는 실제 배포에 사용된 Markdown이 제공됩니다. 기존 `.html` 문서 주소의 호환 이동과 사용자 지정 도메인은 유지됩니다.

신규 처리·보유기간 연장에 필요한 고지·동의는 별도로 갖추어야 하며 기존 동의를 소급 연장하지 않습니다. CCTV 음성, 최소 보유기간, 얼굴인식·국외이전의 미확인 요건과 접근 권한자 명단은 실제 운영에 맞춰 확인해야 합니다. 요청된 문구를 게시했다고 실제 장비·전송·보관 설정이 변경되는 것은 아닙니다.

공개 저장소에는 회원 명부, 서명된 동의서, 계좌 내역, CCTV 영상, 얼굴인식 데이터, 비밀번호·토큰을 올리지 않습니다. 이 사이트는 공개 규정·서식이며 개인정보 입력·저장 기능을 제공하지 않습니다.
