# 대구가톨릭대학교 RCY 규정·정책

Next.js App Router + Markdown 정적 문서 사이트. 웹사이트 릴리스 **4.1.0**.

공개 사이트: https://bylaws.dcu.rcy.kr/

## 편집할 파일

문서 본문은 `content/` 아래 Markdown에서만 읽습니다. HTML이나 JSX에 조문을 다시 작성하지 않습니다.

| 공개 문서 | 원본 |
| --- | --- |
| 회칙 | `content/bylaws.md` |
| 재무 규정 | `content/finance.md` |
| 동아리방 이용 규정 | `content/clubroom.md` |
| 개인정보 처리방침 | `content/privacy.md` |
| 이용약관 | `content/terms.md` |
| 개인정보 동의서 | `content/consent.md` |
| 촬영·초상 이용 동의 | `content/media.md` |
| CCTV 운영·관리 방침 | `content/cctv.md` |

`main`에 Markdown 변경을 커밋하거나 PR을 병합하면 기존 `Next.js Markdown Pages` 워크플로가 검사 → 빌드 → 결과 검증 → GitHub Pages 배포 → 공개 버전 검증을 실행합니다. 로컬 저장만으로 공개 페이지가 바뀌지는 않습니다. 배포 완료 후 열린 페이지를 새로고침합니다.

상단 YAML의 `title`, `description`, `status`, `version`은 필수입니다. `effective_date`는 기존 기본 시행일 `2026-09-01`을 유지하며, `updated_date`는 개정 작성일입니다. 기술적 배포가 규정 의결이나 개인정보 동의를 대신하지 않습니다.

## 삭제된 공개 메뉴와 보존 자료

`lib/regulation-format.mjs`의 `retiredSlugs`가 공개 제외 경로를 관리합니다. 제외된 원본 파일과 Git 이력은 자료 보존을 위해 저장소에 남아 있으나 Next.js 페이지·검색 데이터·Markdown 다운로드를 생성하지 않습니다. 회칙의 기본 감사·선출·임명 조항을 폐지한 것은 아닙니다.

이전 `_includes/`, `_layouts/`, 루트 문서 폴더의 Jekyll 소스는 비사용 자료입니다. 사이트는 canonical `content/*.md`만 읽습니다. 새 문서는 제외 목록에 없는 영문 소문자·숫자·하이픈 경로에 필수 메타데이터를 갖춘 `.md`를 추가하면 자동 생성됩니다. `hidden: true`는 목록 숨김일 뿐 접근 제한이 아닙니다.

현재 문서에 남아 있는 폐기 전 검토·출처 링크는 저장소의 해당 Markdown 보관본으로 연결합니다. 공개 사이트에서 제거한 문서를 관리 메뉴로 다시 노출하지 않습니다.

## 적용 보류·확인 사항

촬영·초상 이용의 모든 목적을 강제하고 미동의자를 모든 활동에서 제외하는 요청은 법적 제한 때문에 **요청안으로만 기록하고 적용 보류**했습니다. 기존 선택표를 없앤 것이 거부권이나 법정 목적별 동의 구분을 없앤다는 뜻은 아닙니다. 구체적 기업·기관명·보유기간·매체를 정하기 전 포괄 제공 동의로 사용하지 않습니다.

CCTV의 음성 녹음, 1년 일괄 보유, 얼굴인식·국외이전에는 문서에 명시한 시정·검토 조건이 있습니다. 윤민기는 CCTV 관리책임자로만 반영했으며, 비어 있는 접근 권한자 또는 일반 개인정보 보호책임자를 임의로 정하지 않았습니다. `xizomi` 표기는 요청 그대로 보존했고, Xiaomi 등 다른 회사의 실제 계약 법인으로 추정하지 않았습니다. 장비 녹음·전송을 원격으로 변경한 작업이 아닙니다.

개인정보 파기와 퇴임 후 권한 회수는 기존 원문과 달라진 보완점을 해당 방침 부칙에 명시했습니다. 원문의 업무별 보유기간은 유지합니다. 게시·수정일과 기존 시행일을 구분하며 새로운 동의나 과거 의결 사실을 소급하여 생성하지 않습니다.

금액 해석: 회의 간식비·식비는 각각 동아리 전체 월 1회, 사무물품비는 동아리 전체 학기 합계입니다. 같은 회의에서 두 항목이 각각 요건을 충족하는 경우를 일률 금지하지 않되 동일 비용의 중복 정산은 금지합니다. 출장 실비 계산·증빙 설명은 기존 재무 절차를 연결한 보충 설명입니다.

## 실행·검증

Node.js 22 이상. 잠금 파일이 있는 경우 `npm ci`를 사용합니다.

```sh
npm ci
npm test
npm run build
npm run verify:export
npm run dev
```

정적 결과는 `out/`. GitHub Pages Source는 GitHub Actions를 유지합니다. `/version.json`에서 릴리스·커밋·문서 해시를 확인하고 `/downloads/`에서 실제 배포 원문을 확인할 수 있습니다. 제외된 경로는 빌드 결과에서 제거합니다. 남아 있는 문서의 기존 `.html` 링크는 새 폴더 주소로 이동합니다.

문서 HTML 정화, 고유 앵커, 문구를 보존하는 조문 카드 변환, 금액·담당자, 공개 제외, 내부 링크와 Markdown 수정의 해시 변화를 테스트합니다. 렌더링·다운로드·버전 해시를 검증한 결과만 배포합니다.

외부 폰트 요청이나 새 추적 스크립트는 추가하지 않았습니다. 원본과 유사한 글꼴 스택을 사용하며 설치된 글꼴에 따라 자폭 차이가 있을 수 있습니다. 회원 명단, 계좌, 서명본, CCTV 영상, 인증정보를 이 공개 저장소에 저장하지 않습니다.
