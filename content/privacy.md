대구가톨릭대학교 RCY(이하 “본회”)는 정보주체의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보 처리방침을 공개한다.

> **적용 범위:** 본회가 직접 관리하는 일반 운영기록은 내부 보관 5년 기준을, 외부 서비스·사업의 처리는 해당 운영기간 기준을 적용한다. 구체적인 기산점과 예외는 제1조에 따른다. 처리방침의 게시만으로 기존 동의의 기간이 연장되거나 얼굴인식·국외이전 동의가 성립하지 않는다.

## 제1조(처리 목적·항목·보유 기간)

1. **동아리 내부 저장은 5년, 외부 저장·이용은 해당 서비스 또는 사업 운영기간**을 기본 기준으로 한다. 본회 내부 보관이란 본회가 관리하는 일반 회원·활동·운영기록을 말한다. 단순히 저장 장소만 바꾸어 기간을 연장하지 않는다.
2. 이 문서의 5년은 **각 기록의 수집·생성일로부터 최대 5년**으로 계산한다. 단순한 열람·복사·인계로 기산점을 다시 시작하지 않는다. 이는 본회의 일반 보관 기준이지 법정 의무 보존기간이나 최소 보관기간이 아니다.
3. 외부의 “운영기간”은 **해당 개인정보를 처리하는 서비스·사업·공개 게시 목적을 운영하는 기간**을 말한다. 운영 종료, 목적 달성, 동의 철회 등으로 불필요해지면 해당 자료를 삭제한다. 외부 기관의 존속기간을 의미하지 않으며, 제공받는 기관별 정확한 종료 기준은 제공 전에 고지한다.
4. 건강정보, 인증정보, 계좌정보, CCTV 및 얼굴인식 데이터에는 아래의 별도 최소 보유 기준을 적용한다. 정보가 먼저 불필요해지면 5년 또는 운영기간이 남아 있더라도 지체 없이 파기한다.

## 제2조(제3자 제공)

본회는 정보주체가 **별도로 동의한 경우에 한하여** 다음의 제공 업무를 수행한다. 제공 전 실제 수령 기관·부서, 목적, 항목, 수령자의 보유·이용 기간, 거부권과 구체적인 영향을 알린다. 법령에 근거한 별도 제공은 그 근거와 요건을 따로 확인한다.

외부 기관에 대한 제공은 해당 서비스·사업 운영기간을 기본 범위로 하되 실제 수령자의 처리 근거와 구체적 보유 종료 기준을 확인한다. 본회의 문구만으로 외부 기관의 보관 정책을 변경하거나 무기한 보유를 허용하지 않는다.

“기업·기관 등”이라는 표현만으로 알 수 없는 모든 수령자에게 제공하지 않는다. 실제 관계 기관별로 고지하고 필요한 근거를 확보한다. 활동 증빙을 위하여 제공한 자료를 수령 기관이 별도 상품 광고나 자체 SNS 홍보에 이용하는 행위는 위 보고 목적에 자동 포함되지 않는다.

촬영물의 내부 공유·SNS·홈페이지 이용 범위와 동의 절차는 [촬영·초상 이용 동의](/media/), 기관별 작성 서식은 [개인정보 동의서](/consent/)를 함께 확인한다. **홍보 목적까지 전부 필수로 묶고 미동의자를 모든 활동에서 배제하는 요청은 적용 보류**하며, 실제 필수 활동 증빙과 공개 홍보를 구분한다.

<h2 id="overseas">제3조(처리 도구·위탁 및 국외이전)</h2>

1. 첨부 원문에 따라 본회는 명부·신청 접수·문서 보관과 RCY Network 운영에 Google LLC의 폼·스프레드시트·드라이브를 이용하는 것으로 기재한다. 접근 권한은 제6조에 따라 최소화하며, 해당 도구를 통한 처리를 원하지 않는 경우 공용 이메일을 통한 서면 접수 방식을 안내한다. 실제 위탁·이전 내용과 대체 접수 창구는 확인하여 고지한다.
2. **촬영된 영상 또는 이미지가 Xiaomi Home 클라우드로 전송·저장될 수 있으며, 사람·움직임 등 이벤트 감지를 위해 Xiaomi의 AI 영상분석 기술을 이용하여 자동 분석될 수 있다. 얼굴 인식을 위해 얼굴인식 데이터를 수집·저장한다.** 이는 운영자가 제공한 처리 내용이며 제품·설정의 확인 결과가 아니다. 얼굴 영상·특징정보 중 실제 수집하는 항목과 저장 위치·기간을 별도로 정한다. 이전 국가를 중국으로 안내한 기존 정보는 실제 계정 지역·계약과 대조하고, 수령 법인·연락처·시기·방법·보유기간·재위탁 관계를 확인한다.
3. 국외이전 전에는 별도 동의 등 적용 가능한 근거와 법정 고지·안전조치 요건을 갖춘다. 필요한 정보와 얼굴인식 처리 근거를 확인하기 전 해당 기능을 시행 승인된 것으로 취급하지 않는다. 이미 사용 중인 기능의 중단·설정 확인 필요성은 [CCTV 방침 제5조](/cctv/#overseas)에 따른다.
4. 아래 항목을 업무·수령자별로 확인한다: **이전 항목, 국가, 시기·방법, 수령 법인명·연락처, 목적, 보유·이용 기간, 거부 방법·절차·효과**. 국내 회사나 익숙한 브랜드를 사용한다는 사유만으로 국외 처리가 없다고 추정하지 않는다.
5. 특정 개인 식별을 위한 생체 특징정보는 일반 활동 사진과 구분하여 민감정보 요건을 확인한다. 일반 회원가입·촬영 동의와 국외이전 동의가 이러한 모든 처리를 자동 허용하는 것은 아니다.

## 제4조(파기)

1. 보유 기간 경과·처리 목적 달성 시 지체 없이 파기한다.
2. 첨부 원문의 월말 일괄 파기 문구는 지체 없는 파기를 늦추는 근거로 사용하지 않는다. 이번 보완안에서는 대상 도래 시 파기하고 **월말에는 누락 여부를 점검**하여 대상·건수·일자를 기록하는 방식으로 정리한다.
3. 전자 파일은 복구 불가한 방법으로 삭제하고 출력물은 파쇄한다. 적법한 별도 보존이 필요한 자료는 목적·범위·기간을 명확히 하여 다른 정보와 분리한다.
4. 공개 게시물·외부 제공본·클라우드·백업과 특징정보는 각각의 삭제 절차를 확인한다. 다른 사람이 가진 모든 사본을 실제로 회수했다고 근거 없이 기록하지 않는다.

## 제5조(정보주체의 권리)

1. 정보주체는 자신의 개인정보에 대한 **열람·정정·삭제·처리정지**를 요구하고 동의를 철회할 수 있다.
2. 일반 개인정보와 CCTV에 관한 열람·정정·삭제·처리정지·동의 철회 요청은 **윤민기 / rcyindcu@gmail.com**으로 접수한다. 본인 확인에 필요한 최소 정보와 요청 대상을 확인하여 처리한다.
3. 원문의 **7일 이내 조치 결과 회신**은 내부 처리 목표로 유지하고, 적용 법령상 처리 절차·기한을 우선한다.
4. 필요한 개인정보 처리가 불가능해져 실제 제한되는 봉사시간 등록 등 업무는 구체적으로 안내한다. 홍보 동의 철회를 일반 동아리 활동 전체의 참여 제한으로 확대하지 않는다.

## 제6조(안전성 확보 조치)

1. 명부 편집 권한은 지원부장(미설치 시 담당 부장)과 회장단으로 한정하고 권한자 목록을 기록한다.
2. **공용 계정의 비밀번호는 1달에 한 번 변경한다.** 공용 계정에는 2단계 인증을 적용하고 복구 코드를 안전하게 보관한다. 변경 일자와 담당자를 기록하되 비밀번호 원문은 회의록·공개 문서에 적지 않는다. 유출 의심·권한자 교체 시에는 정기 변경일을 기다리지 않고 즉시 변경하고 기존 세션·불필요한 권한을 정리한다.
3. 이번 보완안에서는 임원 이탈·직무 변경으로 필요 없어진 권한을 **지체 없이 회수**하는 기준으로 정리한다. 원문의 7일 기한을 퇴임 후 접근을 계속 허용하는 근거로 사용하지 않는다.
4. 학기 1회 권한·보유 현황을 점검하고 기록한다. CCTV 권한자 명단은 별도로 지정하며 현재 미기재 상태를 전체 임원 권한 부여로 해석하지 않는다.

## 제8조(방침의 변경)

이 방침을 변경하는 경우 시행 7일 전부터 홈페이지에 변경 사항을 공지한다. 정보주체에게 불리한 변경은 14일 전부터 공지한다. 새 목적·새 수령자·민감정보·국외이전에 추가 동의가 필요한 경우에는 공지만으로 동의를 대신하지 않는다.

## 부칙 및 변경 범위

기본 시행일은 **2026년 9월 1일**, 이번 개정 작성일은 **2026년 9월 17일**이다. 실제 개정 공고·적용일과 필요한 추가 동의는 별도로 관리하며 과거에 동의·의결·공고가 있었다고 소급 표시하지 않는다.
