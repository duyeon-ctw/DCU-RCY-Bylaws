> 첨부 규정집이 참조하는 A·B·C 원본은 제공되지 않아 **새 서식안**을 작성했다. 이 페이지는 열람·인쇄용이며 입력·서명·제출·서버 저장 기능이 없다. 실제 접수 전 모든 빈칸, 처리 근거, 항목, 기간, 문의처를 확정하고 개인정보 처리방침 및 신청 화면과 일치시킨다. **서명한 동의서나 명부를 GitHub에 올리지 않는다.**

## 공통 작성 원칙

동의를 근거로 수집할 때에는 처리 주체·목적·항목·보유기간·거부권·구체적인 불이익을 먼저 알린다. 필수·선택 여부는 실제 업무에 필요한 범위로 결정하고, 기본 체크나 일괄 동의를 강요하지 않는다. 건강정보·제3자 제공·국외이전·사진 공개는 필요한 경우 독립적으로 선택하도록 한다. 이용약관 동의와 개인정보 동의는 서로 구분한다. [법령 근거](/references/#law-consent)

공통 처리 주체: **대구가톨릭대학교 RCY**. 동의 철회·권리 요청 창구: **[실제 담당 부서와 이메일·전화 확정 필요]**. 공고명·행사명·서식 버전·작성일을 각 접수 건에 연결한다. 거부의 불이익은 아래 안내를 실제 운영에 맞게 구체화하고 없는 불이익을 새로 만들지 않는다.

## 서식 A 회원가입 및 부원 관리

| 고지 사항 | 내용 |
| --- | --- |
| 수집·이용 목적 | 회원 식별·명부 관리, 활동 관련 연락, 출결과 회비 납부 확인 |
| 항목 | 성명, 학번, 학과, 학년, 휴대전화, 이메일. 원문상 기본 항목이며 실제 필요성 확인 후 확정 |
| 보유·이용 기간 | 탈퇴 또는 회원자격 상실 시까지. 목적 달성으로 먼저 불필요해진 정보는 지체 없이 파기 |
| 동의 거부 | 동의를 거부할 수 있음. 동의가 처리 근거인 필수 항목을 제공하지 않으면 해당 회원 확인·연락·가입 업무가 제한될 수 있으며 구체적 범위를 신청 전에 안내 |
| 권리 행사 | 공통 담당 창구로 열람·정정·삭제·처리정지·철회 요청 |

**회원가입 목적 수집·이용: □ 동의함　□ 동의하지 않음**

성명: __________________　작성일: __________________　서명: __________________

### A-1 선택 비상연락처

수집 필요성이 확인된 경우에만 사용한다. 목적은 긴급 연락, 항목은 필요한 연락수단, 기간은 회원 관리에 필요한 기간으로 하되 실제 필요한 행사 범위로 축소할 수 있는지 먼저 확인한다. 제3자의 번호를 적는 경우 그 사람의 개인정보 처리 근거와 안내 방법을 별도로 확인한다. 거부해도 일반 회원가입을 제한하지 않는다. **□ 동의함　□ 동의하지 않음**

### A-2 탈퇴 후 활동 확인 기록 보유

탈퇴 후에도 활동 확인서 발급·재발급을 제공하기 위해 **성명·학번·활동 내역**을 **탈퇴 후 1년** 보유하는 원문 기준안이다. 정식 적용 전 보유 필요성과 적법한 근거를 확인한다. 선택 동의를 근거로 하는 경우에는 아래 항목을 따로 받는다. 거부해도 현재 활동 참여를 제한하지 않으며, 탈퇴 후 기록 삭제로 재발급 대응이 어려울 수 있음을 안내한다. **□ 동의함　□ 동의하지 않음**

## 별지 D 제3자 제공 동의

**기관마다 별지 1장을 작성한다.** 적십자 등록, 1365, VMS를 모두 “봉사 관련 기관”으로 묶어 포괄 동의받지 않는다. 실제 제공하지 않는 기관의 동의를 미리 받지 않는다.

| 필수 고지 | 실제 기재 내용 |
| --- | --- |
| 제공받는 자 | [대한적십자사 ○○지사 등 정확한 기관명 / 확정 필요] |
| 제공 목적 | [단원 등록·관리 또는 해당 봉사실적 등록 등] |
| 제공 항목 | [원문상 성명·생년월일·학교·연락처 또는 봉사 내역 중 실제 필요한 항목] |
| 제공받는 자의 보유·이용 기간 | [구체적인 기간 또는 명확한 종료 기준 / 확정 필요] |
| 동의 거부권·불이익 | 거부 가능. [해당 기관의 등록·실적 인정에 발생하는 구체적인 제한 / 확인 후 기재] |
| 철회·권리 요청 | [본회 창구 및 수령 기관의 요청 절차] |

**위에 특정된 기관에 대한 제공: □ 동의함　□ 동의하지 않음**

성명: __________________　일자: __________________　서명: __________________

“제공받는 기관 규정에 따름”이라는 문구만 적고 보유기간을 비워 둔 채 사용하지 않는다. 봉사포털 비밀번호·인증수단은 이 서식으로 받지 않는다.

## 별지 E 국외이전 동의

국외이전을 **별도 동의에 근거하여** 실시하는 경우에만 사용한다. 다른 적법한 근거를 적용할 때는 그 요건과 공개 의무를 먼저 확인한다. [국외이전 기준표](/privacy/#overseas)에 따라 아래를 모두 채운 뒤 제공한다.

| 고지 항목 | 확정할 실제 정보 |
| --- | --- |
| 이전받는 자·연락처 | [계약상 법인과 연락처] |
| 이전 국가 | [실제 저장·처리·접근 국가] |
| 이전되는 개인정보 | [해당 업무의 실제 항목] |
| 이전 시기·방법 | [언제·어떻게 이전되는지] |
| 이용 목적 | [서비스 및 처리 업무] |
| 보유·이용 기간 | [계약·설정에 따른 기간과 삭제 기준] |
| 거부 방법·효과 | [철회 연락처, 제한 기능, 검증한 대체 방법] |

**구체화된 위 국외이전: □ 동의함　□ 동의하지 않음**

현재 위 항목은 모두 미확정이다. 이 표를 빈칸 상태로 실제 접수에 사용하지 않는다.

## 서식 운영·보관·철회

접수 담당자는 동의 여부, 문서 버전, 일시와 처리 목적을 연결하여 관리한다. 서명·동의 증적의 항목과 보유기간도 적법한 근거와 목적에 맞게 정하며 “분쟁 대비”라는 이유로 무기한 보관하지 않는다. 철회 요청을 받으면 영향을 받는 수집·제공·공개 업무를 구분하여 중단·삭제 등 조치를 검토하고 결과를 알린다. 미동의자 명단을 불필요하게 공유하지 않는다.

전자 서식 구현 시 항목별 동의·거부를 독립적으로 선택하게 하고 선택값을 사전에 체크하지 않는다. 접수 성공 여부와 적용 문서의 사본 또는 재열람 방법을 제공한다. 이 페이지에는 실제 제출 기능이 없으므로 눌러도 저장되지 않는 가짜 제출 버튼을 두지 않았다.
